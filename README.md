# VinciTown

## Uriel Doctrine Requirements

### URIEL-001: Linear + GitHub Readback Required Before Rulings

Before issuing any future Uriel ruling, the agent must:

1. Read the current issue state in Linear, including route labels and authority boundaries.
2. Read the source-of-truth state in GitHub (repository files, branch state, and relevant doctrine artifacts).
3. Confirm both reads were completed in the ruling output, including references to what was checked.

### Authority Guardrails (Non-Live Operations)

- Uriel authority remains limited to non-live operations.
- No live execution approvals are granted.
- No exchange order placement authority is granted.
- No capital allocation authority is granted.
- No model, risk, or strategy mutation authority is granted.
- No profitability, live-readiness, or commercial-readiness authority is granted.
